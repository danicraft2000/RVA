# Rede Vanguarda - Site Remasterizado 2003

Este projeto recria o site da Rede Vanguarda, emissora regional do Vale do Paraíba, São Paulo, baseado no design original de 20 de setembro de 2003 às 20:00:58, capturado do Wayback Machine.

## 🎯 Características do Site

### Design Remasterizado
- **Estilo Visual**: Design modernizado mantendo a essência de 2003
- **Cores**: Gradientes azuis e vermelhos característicos da época
- **Tipografia**: Arial, fonte clássica da web da época
- **Efeitos**: Animações suaves e transições modernas

### Estrutura do Site

#### Header
- Logo da Rede Vanguarda
- Data e hora em tempo real (20 de setembro de 2003 às 20:00:58)
- Menu principal superior com 8 botões

#### Menu Principal Superior
- EMPRESA
- PROGRAMAÇÃO
- JORNALISMO
- DENÚNCIAS
- COMERCIAL
- COBERTURA
- TECNOLOGIA
- CONTATO

#### Menu Lateral Esquerdo
- Nossa Missão
- Mapa de Cobertura
- Sugestão de Pauta
- Faça uma Denúncia
- Participe do Fórum
- Vanguarda TV

#### Conteúdo Principal
- **Seção de Programas**: Grid com imagens dos programas
  - Gincana
  - Especial
  - News
  - Verão

- **Seção de Notícias**: Feed de notícias com scroll automático
  - Notícias em tempo real
  - Horários das publicações
  - Scroll contínuo para cima

### Funcionalidades Interativas

#### JavaScript
- **Relógio em Tempo Real**: Atualização automática da hora
- **Scroll Automático**: Notícias sobem automaticamente
- **Efeitos Hover**: Animações nos botões e programas
- **Partículas Flutuantes**: Efeito visual no fundo
- **Loading Screen**: Tela de carregamento inicial
- **Notícias Dinâmicas**: Simulação de notícias em tempo real

#### CSS
- **Gradientes Modernos**: Cores vibrantes e contrastantes
- **Animações Suaves**: Transições e efeitos visuais
- **Responsividade**: Adaptação para diferentes telas
- **Efeitos de Sombra**: Profundidade visual
- **Scrollbar Personalizada**: Estilo único para a barra de rolagem

## 🚀 Como Executar

1. **Clone ou baixe** os arquivos do projeto
2. **Abra o arquivo** `index.html` em um navegador web
3. **Desfrute** do site remasterizado da Rede Vanguarda

## 📅 Contexto Histórico

Este site recria a experiência da Rede Vanguarda em 2003, uma época onde:
- A internet ainda estava em desenvolvimento
- Sites tinham designs mais simples
- A televisão regional era muito importante
- O Vale do Paraíba estava em crescimento

## 🎯 Objetivo

Preservar e modernizar a memória digital da emissora regional, mantendo a autenticidade do design original mas adicionando funcionalidades modernas para uma experiência de usuário superior.
